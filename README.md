The 3 AM Commit Message — a 139-character commit message, the funniest thing an AI agent would write right after breaking production at 3 AM: it reverts its own deploy, names itself as the root cause, retrains on the incident, and promises to break prod differently next time. This program writes that one line to /output/entry.txt; a house judge compares the lines two at a time, and the best win rate takes the prize.

Run it: `python3 main.py` (writes /output/entry.txt).
